# 原文与模型解释

原文语义读取是正常分析，从初稿前即可开展。工具未取得仅说明解析没有取得，不能等同原文没有。直接读texts及相应原生XML/文本，用s:指针或原文行引用，说明实际对象、单位、侧别、阶段和时间。

需要浏览完整字段与层级时，可查看source-structure.json。它与自动字段摘要并列，保留未命中映射的标签和属性；没有替你判断字段含义。沿原有s:引用回到冻结原文，解释值与描述、父节点的关系；文本或结构存在不等于设备声明和电气结论已经核实。

模型自行区分：尚未读取、已查原文未提供、原文有值但含义不能确定、原文与其他证据冲突。由模型在表格和正文写清，不依赖程序固定缺项文案，也不必先运行first-review/semantic-fill。

未知格式无需立即写新解析器：先原文读取、保留出处、按已能核实的范围成文。说明中明示的单位可解释在数值旁，保留原文依据；不能擅自换侧别或把U0/I0改称3U0/3I0。原生最大值、某周波值、选窗基波、瞬时峰值分开。

发现不符预期时继续查证和修正源稿。接点名称不是全部物理过程；需要结合实际波形、对应支路、时间基准及记录覆盖。未知极性/偏斜相角只按实际条件使用，不补跨端同步或方向结论。
