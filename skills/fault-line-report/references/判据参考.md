# 电气故障分析判据参考

本文件教调用AI怎样从所选变量形成判断，仅作分析参考。它不是程序执行的判据表，不直接设置动作阈值，也不替装置定值。AI按本案实际资料选择适用的方法，写出明确的观察、比较和结论即可；不要求每案逐项论证全部理论。

默认分析范围仍为既定15类变量。本文件的理论关系用于理解已有原生记录和工具结果，不新增正负序计算、测距算法或保护仿真。下面标明“标准依据”的内容来自已核对条款；其余为经典故障分析理论和工程综合方法。

## 1 先形成一条可解释的故障过程

按“故障前 → 首轮故障 → 保护动作 → 切除 → 重合/再次故障 → 记录末段”选取实际存在的阶段。先看波形与接点，再用报文说明是哪套保护做了什么。每个阶段只回答四件事：哪相电压电流改变，哪套保护动作，哪相开关切除或合上，随后故障特征是否消失。

同端选择共同时间窗口比较相量；故障前、故障、切除后的窗口各代表自己的阶段，避免用跨越跳闸沿的混合窗口代表稳定故障值。已有基波计算结果按其实际频率和幅值定义使用。

原生时间、采样时轴及故障零点有依据对应时，可以组织统一过程。未建立对应关系的报文仍可按其自身时间叙述，不为凑统一时间轴反复追查。需回核时查本次关键事件，不检查与选定变量无关的全部通道。

## 2 故障相别和接地特征：看组合特征

### 2.1 常见故障的判断参考

这里的“升高、下降、明显”是与本案同相故障前、邻近稳定窗及实际波形比较，不是统一的百分比门槛。

| 候选故障 | 首先寻找的组合特征 | 进一步怎样判断 |
| --- | --- | --- |
| 单相接地，如A相接地 | A相电流较自身故障前明显增大，A相对地电压下降；直接零序量随故障出现或增大 | 原生A相/接地记载、跳A和A相切除后故障电流消失相互印证时，支持A相接地；B、C相仍有负荷电流是正常现象 |
| 两相短路，如BC相间 | B、C相电流突增、相间电压下降，故障分量主要出现在这两相，零序特征弱 | 若已有同基准相量显示两故障相的故障电流分量近似反向，且无相应接地记载，更支持BC相间故障 |
| 两相接地，如BC接地 | B、C相均出现故障特征，同时出现相应零序电流/电压或明确接地记录 | 与BC相间故障的关键区别是存在接地回路证据；结合零序量、原生相别和两相电压，不仅凭“两相电流大”判断 |
| 三相短路 | 三相电压共同下降、三相电流共同增大，故障阶段三相较对称 | 理想对称三相故障以正序为主，零序接近故障前水平；实际存在不平衡时如实描述，不因小残余量直接改判接地 |
| 发展性故障 | 前后阶段参与故障的相别或接地特征改变 | 分段说明，例如“首轮A相接地，后续发展为多相故障”；不能用末段相别覆盖整个过程 |

原理上，零序是三相同相位分量。相量和满足 `3I0 = IA + IB + IC`、`3U0 = UA + UB + UC`。对理想A相接地故障，以A相为相量基准时，故障点处有 `I0 = I1 = I2`；相间故障点处没有接地电流通路。这些是解释故障类型的理论关系，不要求本工作流新增序分量计算，也不能把故障点的等式直接要求为每个站端实测值的等式。[T2]

### 2.2 零序出现后怎样区分

- 零序变化与相电压下降、相电流突增同步，并在切除后消退，通常支持故障接地特征。
- 单相跳闸后的非全相运行也会产生零序；此时若故障相已经停流，不能仅因仍有零序就写“故障未切除”。
- 原先就有不平衡、通道极性/变比不一致或CT暂态饱和时，也可能出现残余量。只有本案确实出现这些矛盾才局部核查，不把这些可能性逐条写进报告。

接地是否成立是电气判断；雷击、树障、污闪等物理诱因不是本变量的必答内容。波形支持接地时就说明接地特征，不另加一串未开展的原因分析。

## 3 相电压、相电流与零序量：比较什么才有意义

对同一相，比较故障前、故障、切除和重合后的值，并看变化是否与波形一致。优先写能解释故障过程的差异：哪相电压降低，哪相电流增大，未故障相是否仍承载负荷。

例如，某相电流故障前约0.20 A，故障期间约0.18 A，另一故障相为数安培：前一相仍在负荷量级，应写“基本保持负荷电流”，不能因它远小于故障相就说“接近零”。停流应看该相切除后的实际波形与切除后窗口，而不是跨相比较。

若需要解释幅值变化，可以用 `故障窗值/故障前值` 或 `故障窗值−故障前值` 描述同相变化；故障前量很小时直接报告两值，不硬算放大倍数。这里不设统一的增大、降压或停流比例。

原生故障相电压、电流与选窗基波值不是同一个统计量。前者按装置原文含义填写参数表，后者用于说明所选阶段的波形。峰值、全波有效值和基波有效值分别使用。正弦量的峰值为有效值的√2倍，这一关系用于识别定义差别，不用于把未知原生定义强行换算成已知定义。

直接通道标作I0、3I0、U0、3U0时保留原名。乘以正数3只改变幅值、不改变相角；通道反接或采用负极性则会带来约180°变化。一次/二次值和量的单位沿用来源，不通过量级猜单位。

## 4 本端相量关系：从相角到电气解释

### 4.1 先统一比较约定

采用有效值相量，记 `ΔφUI = wrap(φU−φI)`，归一到 `(-180°,180°]`。例如ΔφUI为−100°，表示电流超前该电压100°；不能在文字中写成电压超前电流。参考量整体旋转相同角度，不改变这一差值。[T1]

本项目计算采用固定频率正弦、余弦加直流项拟合；同一窗口的各量以共同参考显示。单个量的绝对相角受窗起点影响，因此比较同窗相对角，不直接拿两段各自归零的角度相减。[T1；项目现有计算口径]

### 4.2 故障相电压与电流

先给出相电压电流幅值和相角关系，再结合故障阶段解释。故障相电压降低、电流增大且呈感性相角关系，可与短路回路主要为感抗的认识相互印证。负荷、过渡电阻、两端馈入及电压测点会影响实测夹角，故相角关系应与波形变化共同使用。

若有相间电压/电流的既有结果，按其实际接线关系比较；没有时不额外要求生成新量。距离保护接线可能采用相间量或零序补偿量，不能把任意一个Ua/Ia夹角视为所有距离元件的动作角。

故障相电压几乎消失时，该小量的角度通常不适合承担强方向结论。此时仍可分析其幅值下降和故障电流，方向判断优先使用装置已记录的方向结果或有实际依据的极化量，不因此取消整段相量分析。

### 4.3 零序电压与电流的方向原理

以下为经典双端线路、简单零序网络的解释模型：电流正方向取“本端母线流向被分析线路”，电压取本端母线对地零序电压，暂不计零序互感。零序网络没有独立电势源，正向接地故障时可写成本端背侧网络关系：

`U0 = −Z0S I0`。

若背侧等值零序阻抗角为θ0S，则 `arg(U0)−arg(I0) ≈ θ0S−180°`。所以在感性网络中，零序电流超前零序电压约 `180°−θ0S` 是可解释的正向特征。比如θ0S取80°时出现约100°的超前关系，是这个模型下的结果，不是一个必须等于100°的判据。

在相同正方向约定下，反向接地故障时，线路及对侧零序网络可表现为 `U0 = Z0R,eq I0`，其相角关系随之改变。AI应先明确所用通道的方向、极性和实际模型，再把实测关系与相应预期比较。若装置使用−3U0作为极化电压，必须把这个负号计入，不能把U0和−U0的角度混用。

可用来理解传统方向元件的比较形式是：

`D = Re[Upol · Iop* · exp(−jθset)]`。

其中Upol是实际极化电压，Iop是实际动作电流，θset是该元件的特性角。对约定为正D对应正向的简单元件，D的符号反映方向；这只说明“为什么要结合特性角和极化量”，工具不按这个式子自动分类方向。SEL的具体零序电压极化示例采用−3U0，并明确考虑线路零序阻抗角；极化电压过小时角度不可靠。[T3，式(3)、正文第12页]

**AI的实际用法：**列出本端3U0与3I0的幅值、共同参考下相角和超前/滞后关系；能明确通道方向及适用特性时，解释它支持哪个方向；只有相角记录时，说明实测关系及其与故障现象的联系即可。只把确实影响该结论的一项疑点留给人工，不为本案另建零序网络研究。

“本端正向”和“被保护线路区内”不是同义词。前方相邻线路故障也可能为本端正向。区内范围判断结合对端方向、两端动作、差动保护信息、测距和接线拓扑；单份本端录波不强求给出完整区内定位。

## 5 保护启动、动作与切除：怎样使用时间

先保存时刻，再说明时间间隔的起止事件。下面的符号仅用于解释口径，不要求本案凑齐所有时刻。

| 量 | 起止事件及判断方法 | 常见的实际表达 |
| --- | --- | --- |
| 保护装置动作时间 | 输入激励满足动作变化的时刻至装置动作时刻；与具体功能和测试/运行条件有关 | 原生明确给出的动作时间按原义引用；只有接点时写接点的实际观测时间 |
| 保护整组动作时间 | 故障开始至断路器分闸回路收到跳闸脉冲 | 若实际只记录到保护出口接点，写“本记录故障至出口约……”并标明观测环节 |
| 本端故障电流持续时间 | 同端故障出现t0至该故障电流最终中断tclear，即tclear−t0 | 写“本端首轮故障电流持续约……” |
| 出口至停流间隔 | tclear−ttrip，包含出口至实际电流中断所经过的环节 | 没有机构行程/主触头证据时不直接称为精确机械分闸时间 |
| 位置接点变化时间 | 分位/合位通道的实际采样沿，或有缺口时的变化区间 | 写位置接点在何时改变，再与停流对应 |
| 重合间隔 | 明确使用“停流至重新通流”“跳闸出口至合闸出口”等哪对事件 | 不混写命令间隔、实际无流间隔和装置整定延时 |

标准依据：[S1]3.1.8、3.1.9分别定义装置动作时间和整组动作时间；不能把从保护启动接点到出口的间隔直接改称从故障开始的整组时间。[S3]5.7给的是装置开关量时间测量性能要求，不把该性能值当作每份录波天然具备的现场精度。

故障起点从本端电压电流突变及相关启动资料确定，触发时刻不当然等于物理故障起点。有采样间隔或数据缺口时，事件落在两个观测点之间就保留区间，不插入不存在的精确时刻。

单相切除的判断：对应相出口或位置变化，随后该相故障电流消失，其他相继续通流。三相切除的判断：三相故障/负荷通流均中断，并与三相出口或位置变化对应。电压若取母线，线路开关跳开后母线电压可能保持；线路开口侧也可能受对侧馈电，故“仍有电压”本身不否定本端切除。

## 6 重合命令、实际合闸与重合结果

| 记录组合 | 可形成的判断 |
| --- | --- |
| 重合命令出现，随后合位恢复或波形重新通流；故障相电压恢复、故障特征消失，后续保持 | 记录支持重合成功；若本次故障经切除后未再现，可描述为具有瞬时性故障的表现 |
| 重合后重新通流，原故障特征再次出现，保护再次动作并切除 | 重合于故障，重合不成功；可说明故障在本次重合时仍然存在 |
| 重合命令出现，但在覆盖相应过程的记录内没有合位恢复或重新通流 | 先写“已发重合命令，未见实际重合完成”；有闭锁/机构记录再解释原因 |
| 记录内没有重合命令、合位或重新通流 | 写“本记录未见重合动作”；不直接等同重合失败 |
| 记录在重合前或刚重新通流时结束 | 重合结果未被本记录完整覆盖，将这一项交人工补证，不追加无关分析 |

重合后故障电流很快再次中断时，要检查是否为加速跳闸，不能只看末段已经停流就说重合成功。重新通流后电流很小但电压正常、合位维持，也可能为空载线路；结合实际运行状态判断，不要求必须恢复故障前同样大小的负荷。

标准依据：[S1]7.4.1.2—7.4.1.5说明重合启动、动作时限、次数与复归的配置要求。本案判定实际重合是否成功仍用命令、位置和波形；不从标准配置要求反推本案已执行了某次重合。

## 7 故障距离、最大值及末段状态

### 7.1 故障距离

逐项取得装置、站端、原文测距、单位及故障阶段，先确认它是公里数、百分比还是其他表示。原生零公里是有效记录，不等同“没有数据”。

双端同一线路、同一次故障、起算端相反且线路长度L明确时，可以看 `dA+dB` 与L是否大致一致，作为测距相互印证；一端接近0、另一端接近L，与近一端出口故障相符。这里不设统一误差容限。偏差较大时先查对象和阶段，只把实际差异交人工审查，不为本报告重新开发测距方法。

只有一端测距，就报告该端装置结果；结合本端电压下降和故障相特征作有依据的位置解释。装置测距、保护某段动作和物理杆塔位置分别看待，不能用固定“Ⅰ段覆盖百分比”替代本案定值。

[S2]8.3.2涉及多厂站综合与双端测距；[S3]5.1.6包括线路故障测距信息。它们提供分析内容的依据，不构成“输入只有一端就拒绝出报告”的要求。

### 7.2 最大零序电流与最大差动电流

原生字段明确说明最大值时，才填最大值表项。记录“故障后一周波电流”只是一个阶段值，不因其数值较大就改称最大值。原生I0与3I0也不混填。

差动电流是装置按本身通道匹配、极性和补偿形成的量，不能把本端相电流或两端电流幅值的简单差当成原生最大差流。若记录没有该最大值，数据记缺项；本案分析继续使用实际取得的电流和动作信息。

### 7.3 最终恢复状态

在记录末段分别看：开关是否维持合位，各相电流是否重新通流，电压是否恢复，故障特征是否消失。把最终结果写具体，如“单相重合后恢复运行”或“三相切除后保持无流”。单独看到母线电压正常不等于线路恢复供电，单独看到电流接近零也不等于母线失压。

若记录只覆盖切除过程，报告截止于已观察到的状态。后续系统实际恢复情况只在资料提供时补入，不作为每份录波报告的必补项目。

## 8 把判断写进报告，而不是扩大核对工作

形成主要结论时，选最直接的两三项依据即可。例如：“B相电压下降、B相电流突增并伴随直接零序量，支持B相接地；跳B后B相电流消失；重合后同类特征再现并再次切除，因此本记录支持重合不成功。”用本案真实值和证据链接替换描述，不套用这一示例的相别与结果。

保护动作先评价其与本次故障过程是否相符。需要评价动作正确性，且本案定值、投入功能和接线资料已经提供时，再对照动作条件及时间配合。标准“四性”是评价框架，不要求普通录波报告逐项做可靠性、选择性、灵敏性和速动性专项试验。[S1，5.1.1]

两轮核对仍只针对所选变量：查值及对象、阶段和时间口径；查文字是否准确表达这些值；查核心结论能否与报文、接点、波形对应。已清楚的内容直接确认，问题修一次再记录。两轮后把实际缺项或冲突留在人工审查数据，不为证明“没有任何其他解释”继续追查。

单项相角、测距或最大差流缺失，通常不妨碍形成有内容的过程报告。目标记录无法确定，关键波形不可读，或核心矛盾使主要过程不能成立时，由调用AI说明具体原因，不生成空壳报告。
