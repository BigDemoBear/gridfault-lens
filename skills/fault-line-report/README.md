# 录波故障分析 Skill

中文检索词：录波分析、故障线路报告、双端故障分析、原生证据核查。

这个 Skill 为 AI 智能体提供 GridFaultLens 的使用指引，帮助其结合原文与计算结果分析双端故障，并保留可供核查的依据。你可以检查报告采用了什么资料、如何计算，以及判断是否得到这些证据支持。

工具安装方式见[项目首页](../../README.md#快速开始)。本目录可放入所用平台支持的 Skill 目录；支持直接读取项目指引的平台，也可以从[SKILL.md](SKILL.md)接入。模型服务由平台提供，仓库不自动配置模型或上传本地材料。

使用时提供录波目录、分析目标和输出位置即可。资料按线路两个站端组织，每端可以关联多组录波；只有一端资料时，报告保留相应缺口。你可以沿报告引用查看原文、波形和计算条件，并结合逐项核查记录复核 AI 的判断。
